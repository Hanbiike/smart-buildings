# Daily log

One folder per day: `docs/YYYY/MM/DD/README.md`.

## Why

Competition work spans weeks and many sessions. The log keeps decisions,
measurements, and failures so future sessions don't repeat past mistakes and
can orient in minutes.

## Convention

- One `README.md` per active day, written/updated as the day goes.
- Language: Russian, with exact paths/commands/scores preserved verbatim.
- Each entry records:
  - **Status**: leaderboard positions, our submissions and their states.
  - **Changed**: what was built/modified, with file links.
  - **Measured**: numbers (train/transfer/public), not adjectives.
  - **Decided**: conclusions and why (especially negative results).
  - **Open**: questions and next steps.
- Negative results are first-class: a ruled-out lever with its numbers is as
  valuable as a win (it stops re-investigation).
- Keep entries short; link code instead of pasting it.
