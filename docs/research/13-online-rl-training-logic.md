## Numbered claims

### A. Advantage normalization

C1. SB3 PPO normalizes GAE advantages per-minibatch by default: when `normalize_advantage=True` (the default) and the minibatch has more than 1 sample, `advantages = (advantages - advantages.mean()) / (advantages.std() + 1e-8)`; the normalization is per-minibatch, not over the rollout buffer; the technique is absent from the PPO paper, so effective sample weighting depends on minibatch composition. Transfer limit: at small minibatches (for example 32) the normalizer is noisy; the ship stack uses minibatch 256 (see C40). Provenance: `https://github.com/vichcraft/pa3-drl-code-reading/issues/6` (carrier S1). Coverage: code reading, not an experiment.

C2. The ship stack replaces per-minibatch normalization with per-worker normalization over free steps only: for each worker `i`, mask `m = (worker == i) & (fr > 0)`; if `m.sum() > 1` then `advs_n[m] = (advs[m] - advs[m].mean()) / (advs[m].std() + 1e-8)`; samples with `fr == 0` keep advantage 0. The code comment states the rationale: a cold climate's large rewards must not set the scale for every other climate. Transfer limit: grouping is by worker scenario list, and lists are shuffled then dealt round-robin, so a worker is not a pure climate. Provenance: `/tmp/rl_zip/skynet_train.py:180-186` (S4); shuffle/split `/tmp/rl_zip/skynet_train.py:42-46` (S4). Coverage: ship implementation (no ablation measured in inspected sources).

C3. CleanRL Sinergym 5-zone BC+PPO reference: 1,000,000 total steps, LR 3.0e-4 annealed, 2048 rollout steps, minibatch 32, 10 epochs, Advantage Normalisation True, clip 0.2, value-clip True, entropy 0.0, gamma 0.99, GAE 0.95; the hybrid improves efficiency/performance by 1% to 11.35% versus prior literature. Transfer limit: single building, tiny minibatch 32 (see C1), from-scratch head over BC features. Provenance: `https://ecmlpkdd-storage.s3.eu-central-1.amazonaws.com/preprints/2024/lncs14949/lncs14949250.pdf` (carrier S1). Coverage: Sinergym 5-zone, single building.

C4. Building2Building reference PPO (SB3, MLP): 14 parallel environments, 5,000,000 steps, LR 5e-5, batch 336, n_steps 672, target KL 0.02, 5 epochs, gamma 0.98, GAE lambda 0.95, clip 0.2. Transfer limit: LR is 6x below the ship 3e-4, and KL-target early stopping is absent from the ship update. Provenance: `https://arxiv.org/html/2607.16534` (carrier S1). Coverage: B2B EnergyPlus houses.

### B. Masking (free steps, votes, shutdown)

C5. Ship free-masking: the residual acts only when the base controller reports free; under the `zt_off` base outside PI hours the step applies the rule action `(cont, disc) = (pc, pd)` with a zero vote mask and the latch untouched; switch votes pass through the latch only when free. Provenance: `/tmp/rl_zip/env.py:56-70` (S5). Coverage: ship implementation.

C6. Held-step masking: with `--hold H`, only sampling steps carry a log-probability (`fr = free * is_sampling_step`); policy log-probs are multiplied by `fr` and the policy-gradient loss is normalized by `fr.sum().clamp(min=1)`; off-hours steps reset the held action so the next free step samples afresh; episode end resets the hold counter. The latch mask is known only after the step, so the log-probability is computed post-step. Provenance: `/tmp/rl_zip/env.py:100-109` (S5); `/tmp/rl_zip/skynet_train.py:196-199` (S4). Coverage: ship implementation.

C7. Action-masking precedent (PPO with rules: no charge/discharge of a full/empty battery, cooling off 10PM-5AM, cooling forced ON above 26.5C): the masked policy matched baseline comfort while cutting cost with zero reward or hyperparameter changes, whereas direct RL cut cost but scored significantly worse comfort (an energy-bill local optimum). Transfer limit: different action space (storage plus schedule), not residual HVAC; no numeric delta in the digest. Provenance: `https://hal.science/hal-04299564/document` (carrier S1). Coverage: single-building energy-management simulation.

C8. Filter-masking precedent (BOPTEST v0.9.0, 5 seeds, 60 episodes per method): intervention-aware primal-dual training lowers raw pre-filter violation and total safety-layer reliance (both p < 1e-4) with no significant energy regression; guard-off evaluation confirms the gain is policy-level rather than filter-repaired. Lesson for the ship stack: closed-loop metrics where the rule repairs residual actions certify nothing about the residual itself. Transfer limit: safety-filter setting, not residual PPO. Provenance: `https://arxiv.org/html/2606.09778` (carrier S1). Coverage: BOPTEST v0.9.0 closed loops.

C9. Robust PLR (train only on PLR-selected levels, stop gradients from randomly sampled levels) generally beats vanilla PLR; but under uncertainty-based ActivePLR sampling, the masked-gradient RPLR variant is worse than full-gradient ActivePLR. Transfer limit: applies only if a level-replay curriculum is added; the ship stack has none. Provenance: `https://ar5iv.labs.arxiv.org/html/2312.10289` (carrier S1). Coverage: Sinergym 5-zone plus generated weather environments.

C10. In-repo masking precedent (slot-PPO): shutdown steps carry no gradient but count for GAE and value targets; BC initialization zeroes memory-feature columns (ZMEM (16,), AMEM (12, 13), WMEM (10,)) for a stable P-only start. Transfer limit: slot-linear architecture, not the FlatNets residual. Provenance: `tools/slot_ppo.py:14-16,54-57` (S9, in-repo). Coverage: implementation note.

### C. DR curricula and building pools

C11. Naive uniform DR over weather (Sinergym 5-zone, 3,000,000 steps): DR/RPLR reach +9% reward over RBC on the base environment, but vanilla RL is +8% better than DR/RPLR there; on 5 extreme-weather environments DR matches RBC (about 0% gain); the digest attributes this to unrealistic sampled environments. Transfer limit: weather-only DR with fixed building geometry. Provenance: `https://ar5iv.labs.arxiv.org/html/2312.10289` (carrier S1). Coverage: Sinergym 5-zone base plus 5 extreme-weather environments.

C12. ActivePLR (uncertainty-driven realistic environment generation plus replay): +9% over vanilla RL on the base environment, +24% over RBC, +3% averaged over 6 environments, 15% relative decrease in days with ASHRAE violations versus vanilla RL; the low-to-high-fidelity reward drop shrinks from 8.5% (vanilla) and about 7% (DR/RPLR) to 6.1% (ActiveRL) and 3.1% (ActivePLR). Transfer limit: needs an uncertainty-ranked realistic generator; the ship generator is config-based (see C39). Provenance: `https://ar5iv.labs.arxiv.org/html/2312.10289` (carrier S1). Coverage: 6 Sinergym environments, fidelity jump.

C13. NOMAD-RL adaptive physics-informed DR (neural spline flows over correlated/multimodal thermal-zone parameters plus plausibility/controllability costs), recurrent PPO, 6,000,000 steps, PID-reference-normalized reward: 8.7% worse (higher cost) than non-randomized recurrent PPO on the nominal zone, but on a shifted-dynamics zone -60.1% cost versus PID and -51.4% versus non-randomized PPO, remaining 46.6% above exact-model MPC. Transfer limit: zone-model DR with an LSTM policy; the ship policy is a feedforward residual. Provenance: `https://arxiv.org/html/2609.05822` (carriers S1/S3). Coverage: nominal plus shifted-dynamics zones.

C14. Building2Building scale (6000 EnergyPlus environments): multi-building PPO (16 parallel environments, new building every episode reset, 4,000,000 steps, 9 seeds) transfers to 100 held-out houses but with a long tail of transfer failures versus consistent per-building specialists; the cross-domain transformer policy (4 buildings in parallel, resample every 10 PPO updates, 1,000,000 steps) adapts to unseen buildings and beats reactive control on some of 20 test buildings. Transfer limit: from-scratch control with no residual base. Provenance: `https://arxiv.org/html/2607.16534` (carriers S1/S3). Coverage: 100 held-out houses (MLP), 20 test buildings (transformer).

C15. Ship pool ladder (Sibling-reported, honest bill, held-out generated judge): shipped-only 0.011117 at 250k; +200 generated scenarios 0.011009 at 250k (delta -0.000108 versus shipped-only); +720 generated scenarios 0.010868 / 0.010859 / 0.010744 / 0.010870 at 250k-1M (best delta -0.000373 versus shipped-only near 750k); 2700 generated scenarios not better than 720. Transfer limit: the judge is held-out generated buildings, not the board; absolute values are judge-specific. Provenance: notebook-cells-digest/F-track (S11). Coverage: held-out generated judge, honest bill.

C16. Cross-building training: single-building policies routinely fail on other buildings; training across a building distribution reduces the need for accurate per-building models; conditioning the policy on building parameters further improves dynamics adaptation. Related fast-adaptation numbers: MetaEMS (CityLearn, SAC backbone, 8 train / 3 held-out buildings per climate zone over 4 zones) converges on new buildings in 3 episodes versus 5-7 for pretrained/MAML/RL-MPC/scratch baselines, with 5.45% average cost reduction versus RBC, and cites RL needing up to 5,000,000 steps to match a feedback controller on HVAC; HVAC-DPT (Decision-Pretrained Transformer, in-context, no parameter updates) cuts energy 45% versus baseline on unseen buildings. Transfer limit: different frameworks (meta-learning, in-context); informative for warm-start expectations, not directly reusable in residual PPO. Provenance: `https://arxiv.org/html/2607.16534` (carrier S3); `https://arxiv.org/html/2210.12590v2` (carriers S1/S3); `https://www.climatechange.ai/papers/neurips2024/50` (carrier S3). Coverage: B2B transfer, CityLearn 4-zone split, HVAC-DPT unseen buildings.

C17. Ship pool mechanics (Source-verified): the pool is drawn from `data/gen/manifest.jsonl` excluding `selection_set.json` scenarios and error rows, requiring `config.gin`; the draw takes n_cold scenarios each of fairbanks/minneapolis plus n_other each of atlanta/denver/phoenix/singapore with a single seed, and aborts on any overlap with `selection_extra.json`; workers loudly skip unbuildable generated floor plans at start (for example the corner-CV build failure on 2026-10-31) and raise only if no scenario in the list builds. Sibling lesson: hash the training pool, because different machines drew different pools. Transfer limit: the pool is manifest- and seed-dependent and must be recorded per run. Provenance: `/tmp/rl_zip/skynet_train.py:49-67` (S4); `/tmp/rl_zip/env.py:36-45` (S5); lesson S11. Coverage: implementation.

### E. LR schedules and overtraining

C24. Ship LR schedule (Source-verified): linear decay to 0 at `--steps`, `lr = base_lr * max(0, 1 - steps/steps)` with default base LR 3e-4. Transfer limit: the decay horizon equals `--steps`, so resuming with a larger `--steps` reshapes the schedule mid-run. Provenance: `/tmp/rl_zip/skynet_train.py:168,75` (S4). Coverage: implementation.

C25. Without LR decay everything turns down after about 750k steps; the B1 variant (linear LR to 0, 2048 steps per worker) improved to 1M steps then stayed flat within +-0.00007 (Sibling-reported). Transfer limit: B1 uses 4x the rollout per worker (2048 versus 512); flatness is judge-measured (see C19). Provenance: notebook-cells-digest/F-track (S11). Coverage: generated judge.

### F. Reward normalization and billing

C29. Ship reward scale (Source-verified): each step reward is multiplied by 10.0 before buffering, so GAE and value targets see scaled rewards, and the logged reward mean divides back by 10. The `ResidualPID` wrapper defaults are episode 576 steps, warmup 0 steps, residual scale 0.3, reward scale 10.0, with action mapping `continuous = clip(pid_continuous + SCALE * a, -1, 1)` for `a` in [-1, 1]^n and discrete actions staying with the PID; the occupancy normalization constant is 125.0 as in evaluate.py. Transfer limit: residual scale interacts with free-masking (C5); the ship PPO run uses scale 1.0 (C40) while the wrapper default is 0.3. Provenance: `/tmp/rl_zip/skynet_train.py:79,162,208` (S4); `/tmp/rl_zip/sbrl.py:1-10,63,73-100` (S7). Coverage: implementation.

C30. Honest bill (Source-verified): the boiler flow is billed at the tank actual temperature `supply = max(current_tank, return)` plus dissipation plus the tank-change term, floored at 0.0; dynamics are unchanged, only the gas number the reward reads. The shipped boiler bills flow x (Tsp - Tret), so heat drawn while the setpoint is below tank temperature is never paid for (forum 752142). The patch is enabled by `bill=honest` params in training workers and evaluation, is idempotent, and is not used by gas audits, which keep the shipped bill. Transfer limit: training/eval-only; the board uses the shipped bill, so honest-bill gains that exploit billing mismatch do not transfer (see C31 for the measured offset). Provenance: `/tmp/rl_zip/sbrl.py:31-53` (S7); `/tmp/rl_zip/skynet_train.py:102`, `/tmp/rl_zip/env.py:29-30`, `/tmp/rl_zip/skynet_eval.py:69` (S4/S5/S6). Coverage: implementation.

Transfer limit: b8 only; the offset is scenario-dependent with fairbanks dominating. Provenance: `/tmp/rl_zip/curves.json:673-679` (rule_b8), `/tmp/rl_zip/curves.json:687-701` (honest.rule, honest.rl5m), `/tmp/rl_zip/curves.json:914-920` (cma_rule) (S8). Coverage: b8-held-out, 5 climates.

No measured ship gain for the paired reward appears in the inspected sources. Transfer limit: the ship default is raw reward x10 (C29), not a normalized reward. Provenance: `https://arxiv.org/html/2607.16534` and `https://arxiv.org/html/2609.05822` (carrier S1); `/tmp/rl_zip/skynet_train.py:89`, `/tmp/rl_zip/env.py:50-52,73-75` (S4/S5). Coverage: papers plus implementation.

### G. Rollout and update mechanics

C34. Shared-counter rollout (Source-verified): every worker samples with its own copy of the net until n_steps x workers total steps; a shared spawn-context counter guarded by a lock allocates steps, so fast buildings contribute more steps and no worker waits for the slowest at every step; each worker returns its samples plus a bootstrapped last value. Transfer limit: per-worker step counts vary run to run with speed and RNG; resume does not restore the in-flight position (C36). Provenance: `/tmp/rl_zip/skynet_train.py:152-159` (S4); `/tmp/rl_zip/env.py:82-113,132-154` (S5). Coverage: implementation.

C35. PPO update (Source-verified): 4 epochs, minibatch 256, clip 0.2, vf_coef 0.5, loss = pg + 0.5 * vf with no entropy term; gradient norm clipped at 0.5; clip fraction and entropy are logged but entropy has zero weight. GAE runs per worker with gamma 0.995 and lambda 0.95, bootstrapped at the rollout cut with the last value. Transfer limit: zero entropy weight risks premature exploration collapse (precedent class in C27). Provenance: `/tmp/rl_zip/skynet_train.py:74-77,169-203` (S4). Coverage: implementation.

C36. Net and runtime (Source-verified): FlatNets with d 64 and depth 2; torch uses 2 threads on the main process and 1 per worker; `latest.pt` is written every 10 updates; a snapshot plus a background held-out evaluation is launched every 250,000 steps.
